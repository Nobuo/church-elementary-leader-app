# LINE用テキスト表示の改善 — クラスタイプ別ラベル表示

## 概要
LINE共有用テキスト（`line-message-formatter.ts`）の表示を変更し、各週のクラスタイプに応じた説明ラベルとグループ名を表示する。現状は「📚 分級あり」と「グループ 1 / 2」のみだが、より具体的なクラス内容がわかるようにする。

## 背景
1ヶ月のクラスは以下のパターンで回る（※分かれる週も初めは一緒で途中から分かれる）：

| 週 | クラスタイプ | グループ表示 |
|----|-------------|-------------|
| 第1週 | 全体クラス（遊ぶ） | ラベルなし（合同3人、名前のみ） |
| 第2週 | 1~3年と4~6年に分けてクラス | 1~3年 / 4~6年 |
| 第3週 | 子供達主体のクラス（子供がやりたいこと） | ラベルなし（合同3人、名前のみ） |
| 第4週 | 1~4年と5~6年に分けてクラス（5~6年は心の話・ディスカッション） | 1~4年 / 5~6年生 |
| 第5週（ある月のみ） | 全体クラス（遊ぶ） | ラベルなし（合同3人、名前のみ） |

## 現状の問題
- `line-message-formatter.ts` は `isEvent` → 「🎉 イベント日」、`isSplitClass` → 「📚 分級あり」の2種類のタグのみ
- グループラベルは常に「グループ 1」「グループ 2」で、学年ベースのラベルに対応していない
- 分級の種類（1-3/4-6 vs 1-4/5-6）を区別するデータがスケジュールにない
- 合同日の種類（イベント/遊ぶ vs 子供主体）を区別するデータもない

## 期待される表示イメージ

```
📅 2026年4月 リーダー担当表

4/5（日）
  メンバーA・メンバーB・メンバーC

4/12（日） 📚 1~3年と4~6年に分けてクラス
  1~3年: メンバーD・メンバーE
  4~6年: メンバーF・メンバーG

4/19（日）
  メンバーH・メンバーI・メンバーJ

4/26（日） 📚 1~4年のクラスと、5~6年生が心の話を話すクラス
  1~4年: メンバーK・メンバーL
  5~6年生: メンバーM・メンバーN

※ヘルパーの方で難しい日がありましたら教えてください。調整します。親の方はすみません、代わりの方をご自分で見つけていただき、変更したら教えてください。
```

## 必要な変更の方向性

### データ層の拡張（検討が必要）
- Schedule エンティティに分級タイプ（`splitType`）を追加する可能性
  - 例: `'standard'`（1-3/4-6）、`'senior-discussion'`（1-4/5-6）
- もしくは、週番号から自動判定するロジックを入れる

### LINE フォーマッターの変更
1. **タグ表示**: `isEvent` のタグ（🎉 イベント日）は不要 → 削除。`isSplitClass` の場合のみ、分級タイプに応じた説明文を表示
2. **グループラベル**: 分級日は「グループ 1/2」→ 学年ベースのラベル（「1~3年」「4~6年」等）、合同日は「グループ 1:」を削除し名前のみ表示
3. **フッター**: 注意書きテキストを末尾に追加
4. **合同日（非イベント）**: 第3週のような日はタグなしで「グループ 1」のみ
