# イベント名の入力・表示機能

## 概要
スケジュール設定でイベント日にイベント名（任意）を入力できるようにし、LINE用テキスト出力時にそのイベント名を記載する。

## 背景
現在イベント日は「イベント日」とだけ表示されるが、具体的なイベント名（例: クリスマス会、運動会など）がわかると、LINE共有時に受け取る側にとってわかりやすい。

## 仕様
- イベントトグルON時にイベント名の入力欄を表示する
- イベント名は**任意**（空欄でもOK）
- LINE用テキスト出力でイベント日の場合、イベント名があれば記載する
- イベント名がない場合は従来通り「イベント日」表示

## 期待される効果
- LINE共有テキストの情報量が増え、受け取る側がスケジュールを把握しやすくなる

## 影響範囲
- `Schedule` エンティティ — `eventName: string | null` プロパティ追加
- DBマイグレーション — `schedules` テーブルに `event_name` カラム追加
- スケジュールAPI — イベント名の保存・取得
- UI（スケジュール設定画面）— イベントトグルON時に入力欄表示
- LINE用テキストフォーマッター — イベント名の出力
- CSV出力 — イベント名の出力（任意）
